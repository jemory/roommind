# House target as the base layer

A household-level House Target (a heat/cool comfort pair plus an eco pair) with an optional House Schedule bound to Home Assistant `schedule.*` helper(s) through a selector entity is adopted as the base layer of the target model, with per-room settings layered on top of it, because a ducted Central Plant already conditions every open register at once and v3.0.0 left every household re-typing the same comfort and eco pair, the same schedule shape and the same preheat and price-shift choices room by room; occupancy, with live sensors and learned Occupancy Trends behind each room's Room Priority, arbitrates between conflicting room settings rather than a flat override weight, so an occupied room with a setting outranks an empty one and a manual override outranks a room schedule within the same occupancy tier. The alternatives are rejected for cause: no house layer keeps the per-room duplication that a whole-home plan already pays for once; a house layer implemented as a pseudo-room couples a setting that is a household choice to one Thermal Zone's heat-loss model, its occupancy trend and its Guardrail Band, and lets one room's sensor physics decide what the rest of the home inherits; and the flat 3.0 override weight stays blind to whether the room carrying the setting is occupied at all, so it cannot express an occupied room outranking an empty one, nor occupancy choosing which room receives the house target when no room has a setting. The documented precedence contract therefore changes: a room's own schedule block or manual override outranks the house for that room, a House Override holds below a room schedule block, the House Target sits above only the room's own comfort/eco band, and an empty following room takes the house eco pair instead of the house comfort pair. Upgrades stay inert: the persisted `house` block starts disabled (`enabled=false`), so no target, mode, schedule, preheat or price shift changes until the occupant writes a house target, while a fresh install starts enabled at 21/24 °C with 17/27 °C eco, and a room set to Independent keeps today's v3.0.0 behaviour exactly.
